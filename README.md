# Finançarias — Mobile

App mobile do Finançarias (Expo + React Native + TypeScript), consumindo a API GraphQL do
backend ([`LHPalma/Financarias`](https://github.com/LHPalma/Financarias), repositório irmão).

## Rodando localmente

```bash
npm install
npx expo start
```

No terminal, escolha abrir num emulador Android, simulador iOS, no navegador, ou no app Expo Go.

Roteamento é por arquivo (`src/app/`), via [Expo Router](https://docs.expo.dev/router/introduction).
